## Тесты API

`npm test` запускает 32 теста в `test/api.test.js`. Тесты поднимают приложение на свободном порту с базой в памяти и проверяют сценарии через HTTP:

- создание сотрудника, пустое имя, дубль имени без учёта регистра (и для кириллицы)
- лишние пробелы в имени, сортировка списка по алфавиту
- старт и стоп таймера, длительность записи
- **повторный старт таймера — 409**, в базе остаётся одна активная запись
- новый старт после остановки, независимые таймеры разных сотрудников
- стоп без активного таймера, пустое описание, несуществующий сотрудник
- **пустой отчёт**: без сотрудников и с сотрудником без записей за период
- итоги по сотрудникам, фильтр по сотруднику
- запись на границе периода, точные границы (начало входит, конец не входит), порядок записей
- активный таймер в отчёте, будущий период
- период не в формате ISO, неверный `employeeId`
- слишком длинные имя и описание, тело запроса не JSON
- часы сервера ушли назад: длительность и итог не становятся отрицательными
- ответ API несёт время сервера в заголовке `X-Server-Time`
- неизвестный маршрут API — 404, сервер отдаёт страницу приложения
- **сохранение данных**: тест пишет в файл базы, закрывает её, открывает снова и находит данные

## Тесты интерфейса

`npm run test:ui` запускает 12 тестов в `e2e/ui.spec.js` в браузере Chromium. Playwright сам запускает сервер на порту 3457 с новой пустой базой во временной папке. Перед первым запуском браузер нужно скачать один раз:

```bash
npx playwright install chromium
```

Что проверяют тесты:

- **пустой отчёт** показывает подсказку вместо таблицы
- новый сотрудник появляется в списке и в фильтре отчёта, дубль даёт ошибку рядом с полем
- двойная отправка формы создаёт одного сотрудника
- старт и стоп таймера: счётчик идёт, статус для программ чтения с экрана, запись и итог в отчёте
- **повторный старт** со старой страницы: ошибка 409 и кнопка «Стоп»
- таймер из другой вкладки появляется без перезагрузки (тест подменяет часы, чтобы не ждать 30 секунд)
- текст в поле задачи не пропадает при обновлении списка
- счётчик считает по часам сервера, а не браузера
- ошибка первой загрузки видна на странице
- на телефоне (375 пикселей) страница не прокручивается вбок
- кнопки и поля не ниже 44 пикселей

Тесты ловят настоящие поломки. Я проверил это так: убрал защиту от двойной отправки и блок прокрутки таблицы. Оба теста упали. После возврата кода они снова прошли.

После прогона во временной папке остаётся файл базы последнего прогона. Удалить его сразу нельзя: Playwright вызывает очистку, пока сервер ещё работает, и Windows держит файл открытым. Поэтому каждый прогон сначала удаляет файлы прошлых прогонов (`e2e/cleanup.js`).
